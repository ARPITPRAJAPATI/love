# Happy Birthday, Baby! ❤️ - Digital Scrapbook & Love Album

A digital scrapbook celebration website featuring interactive photo binders, polaroid memories, audio player, handwritten notes, and animations.

## ✨ Features
- **Interactive Photo Binder**: Flip through vintage scrapbook spreads, stickers, and handwritten memories.
- **Polaroid Gallery**: Drag, hover, and view moments with retro photo card effects.
- **Music & Audio Tape**: Retro cassette player interface with interactive playback.
- **Micro-Interactions**: Confetti, floating hearts, and tactile sound effects.

## 🚀 Getting Started

### Local Development
1. Clone the repository:
   ```bash
   git clone https://github.com/ARPITPRAJAPATI/love.git
   cd love
   ```
2. Start the local server:
   ```bash
   npm start
   ```
   Or open `index.html` directly in your browser.
3. Open `http://localhost:3000` in your web browser.
